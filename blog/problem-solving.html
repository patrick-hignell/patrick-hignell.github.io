Problem Solving

During the JavaScript kata, there was one problem that I became stuck on much longer than the rest. The challenge "deBee" had us having to take a string such as "Help! buzz I'm buzz buzz surrounded buzz by buzz buzz bees!!", removing all of the "buzz" words and returning a string such as "Help! I'm surrounded by bees!!".

For quite a while I had forgotten about the array.filter method and missed that the handbook had suggested using it! This sent me down the completely wrong path when I initially tried to solve the problem.

I started by writing pseudocode of what I thought needed to happen next-

// make array of words.

// check if array elements are queal to buzz (compare in lower case but preserve original capitalisation)

// remove buzz

// join string and return

First I split the original string in to an array that I declared, using a space as the delimiter. I then wanted to make a copy of this array, however this is where I made my first mistake.

let stringArray = sentence.split(' ')

let newStringArray = stringArray

In case you missed it (I did!), by declaring a new array which is equal to a different array, you create what is called a "shallow copy". Any objects or arrays within a shallow copy are just references (like shortcuts) to the objects or arrays within the original array. To declare a deep array you can declare it like this-

let newStringArray = [...stringArray]

My function ended up looking something like this-

function deBee(sentence) {

let stringArray = sentence.split(' ')

let newStringArray = stringArray

stringArray.forEach(function (element, index) {

console.log(element.toLowerCase())

if (element.toLowerCase() === 'buzz') {

console.log('is buzz at ' + index)

console.log(newStringArray.splice(index, 1))

}

})

console.log(newStringArray)

console.log(stringArray)

return newStringArray.join(' ')

}

It wasn't working, hence I was using console.log to track each of the changes. I also googled copying assays which alerted me to the fact that a shallow copy of an array could cause problems. It was by console logging that I realised there was a different outcome depending on whether I was making a shallow or deep copy. It still was not however producing the right result. I could see due to the console logs that the for each statement was removing components whilst it was trying to alter subsequent components and so I realised that this approach was not going to work. I sat and thought through the problem from the beginning and tried to construct a question in my mind which might help me google the right answer. During this process I recalled that I had previously seen filter as a method and thought that this would be a good line of enquiry. I suppose trying to describe the problem in my mind for google could be seen as similar to the rubber ducky method. This line of enquiry eventually led me to my final submission-

function deBee(sentence) {

let stringArray = sentence.split(' ')

let newStringArray = stringArray.filter(

(string) => string.toLowerCase() !== 'buzz'

)

return newStringArray.join(' ')

}

It worked! Even more satisfyingly it was more concise and elegant than my original effort!
