JavaScript & the DOM

By now you should be familiar with HTML and CSS, the former gives the basic information and structure to a webpage, the latter makes it look nicer and easier to interact with. For some websites, those are all of the ingredients you need. However if you want some more advanced actions to occur on your website, for example, things to move around, messages to pop up or really the webpage to change in any way after loading, you will need JavaScript.

If HTML is the skeleton and CSS is the skin, JavaScript is the muscle.

First thing to note, if you have heard of the coding language Java before, just know that Java and JavaScript are different languages! JavaScript uses various pieces of logic to enable complex interactions with the webpage. These include variables, arrays, objects, conditional statements, loops and functions-

Variables- store data values which can be manipulated and compared. Examples include bools (true or false), integers (whole numbers), floats (numbers with decimal points) and strings (words or sentences). Declared using let (for variables that can later be changes) and const (for variables which will remain the same after declaration). If you see a variable being declared by var, this is an old way of declaring and is advised against as it does not specify if the variable should be able to be changed or not.

const name = 'Nigel the Magnificent'

let age = 111

Arrays- lists of variables. Can contain any variable or a mix of different variables. Declared by surrounding variables in square brackets [], separated by commas. Can be accessed by referring to the index of the variable. Note indexes are counted starting at 0. You can use methods to change an array such as push() which adds to the end of the array and pop() which removes the last variable from the array. Note, declaring an array as const means that it cannot be assigned a completely new array, however the variables within the array can be changed and the array can still be added to and removed from.

const magicTricks = [

'one card monte',

'52 card pick up',

'dude wheres my car?',

'pulling a hat out of a rabbit',

"I'll do this with my hands",

]

magicTricks[3] = 'something less horrifying for the children'

magicTricks.push('cutting a pigeon in half with a stick')

let favouriteTrick = magicTricks[0] //favouriteTrick is now "one card monte"

Objects- like an array, it is a variable that can hold many variables, however unlike an array, these are not accessible through a particular index but through key-value pairs where each key (or property name) has a different value. Declared by surrounding variables in curly brackets {}, separated by commas, each key denoting its value with a colon. Variables are accessible either by using objectName.propertyName or objectName["propertyName"]. The former is usually easier to type out however the latter can be powerful as a changeable variable can be put in place of the property name so what is accessed can change depending on the situation.

const minion = {

name: 'Bilbo',

age: 50,

profession: 'Burglar',

}

console.log(minion.name) // will log "Bilbo"

console.log(minion['age']) // will log "50"

let selectedProperty = 'profession'

console.log(minion[selectedProperty]) // will log "Burglar"

Before we talk about loops and functions, we should first talk about the "control flow". The control flow is the order in which the statements in the code are executed. The default flow is for the computer to read the script from the beginning to the end, top to bottom, just like reading a book. There are however certain statements that it can come across which alters the flow-

Conditional statements- such as If/else can mean that different sections of the code can be run or ignored depending on whether criteria are true or false. Operators can be used such as == or === for loose or strict equality, > or < for greater than or lesser that etc.

let amIAConjurerOfCheapTricks = false

if (amIAConjurerOfCheapTricks == false) {

console.log('I am not trying to rob you, I am trying to help you')

} else {

Console.log('I am not trying to help you, I am trying to rob you')

} // will log "I am not trying to rob you, I am trying to help you"

Switch statements can also be used to perform one of a number of different actions depending on the value of a variable.

let stubbornness = 5

switch (stubbornness) {

case 5:

console.log("you shall not pass!")

break

case 4:

console.log("you might not pass!")

break

case 3:

console.log("pass or not pass, I don't care!")

break

case 2:

console.log("you could pass if you wanted to!")

break

case 1:

console.log("I would really love it if you would pass!")

break

default:

console.log("I don't know how I feel about you passing!")

break

} // will log "you shall not pass!"

Loops- loops are used to go over and over a certain section of code until certain conditions are met. A common example is a "for loop" in which an iterator is generally increased every time a loop is completed, and once the iterator reaches a certain number, the loop finishes. Think about doing weights at the gym. You set yourself a target of 20 reps and until that target is reached, each loop you will perform the action of lifting the weight. You might even count under your breath until you reach the target and then you stop the loop and move on to the next exercise.

let psychicLinkDuration = 20

for (let i = 0; i < psychicLinkDuration; i++) {

console.log('Hold the door!')

} // will log 'Hold the door!' x 20

Functions- functions are a section of code which can be repeated as often as it is called. It is useful for actions which occur a number of times or it is not known haw many times they will need to be called. Functions can take parameters which are variables which could change aspects of the function or be altered in some way and returned. To declare a function you must start with the keyword function, followed by the functions name. This is followed by parentheses () which if there are any parameters should be included between the parentheses, separated by commas. Finally the function itself is included between curly brackets {}. To return a value, use the keyword return within the curly brackets before the value that is to be returned. Crucially, a function is not performed until it is invoked. You can invoke a function by writing in the code the name of the function followed by parentheses containing the parameters you wish to be used in the function (or just () if there are no parameters).

let spell = 'wingardium leviosaar'

let featherFloating = false

function checkSpell(testSpell) {

if (testSpell == 'wingardium leviosa') {

featherFloating = true

} else {

console.log("It's wingardium leviosa, not " + testSpell + "!")

}

}

checkSpell(spell) // will log "It's wingardium leviosa, not wingardium leviosaar!"

Lastly we should discuss how JavaScript can actually be used to interact and alter information displayed on a website and so we must discuss the DOM! The DOM or Document Object Model is the programming interface through which scripts using languages such as HTML and JavaScript can interact with a webpage. It is essentially a hierarchy or genealogy of the objects which make up the webpage, each object located on its own node, with a parent node above it (except for the document) and for some nodes one or more child nodes below it. A common type of node is an element such as the HTML elements <body>, <div> <table> etc. Every element is a node but not all nodes are elements. Non element nodes include-

Text Nodes: The text within an element. E.g. in <p>Hello World</p>, "Hello World" is a text node.

Comment Nodes: Comments within the HTML, e.g. <!-- This is a comment -->

Document Nodes: the document itself.

Attribute Nodes: attributes of an element. E.g. id/ class.

DocumentType Nodes: The declaration of the type of document. E.g. <!DOCTYPE html>

JavaScript can be used to interact with the DOM in various ways. You can use event listeners so that a script will run when a particular event is performed by the user (e.g. a button is clicked) or change or add HTML elements by using document.getElementByID("Example-ID") which returns a single element by that id or document.GetElementByClassName("example-class") which returns an array. You can then for example change the text within the element (e.g. using document.getElementByID("todaysLesson").innerHTML = "Transfiguration") or add a class which could then result in a different aesthetic by using CSS (e.g. using document.GetElementByClassName(")[0].classList.add("invisible")).
