JavaScript & the DOM

By now you should be familiar with HTML and CSS, the former gives the basic information and structure to a webpage, the latter makes it look nicer and easier to interact with. For some websites, those are all of the ingredients you need. However if you want some more advanced actions to occur on your website, for example, things to move around, messages to pop up or really the webpage to change in any way after loading, you will need JavaScript.

If HTML is the skeleton and CSS is the skin, JavaScript is the muscle.

First thing to note, if you have heard of the coding language Java before, just know that Java and JavaScript are different languages! JavaScript uses various pieces of logic to enable complex interactions with the webpage. These include variables, arrays, objects, conditional statements, loops and functions-

Variables- store data values which can be manipulated and compared. Examples include bools (true or false), integers (whole numbers), floats (numbers with decimal points) and strings (words or sentences). Declared using let (for variables that can later be changes) and const (for variables which will remain the same after declaration). If you see a variable being declared by var, this is an old way of declaring and is advised against as it does not specify if the variable should be able to be changed or not.

const name = "Nigel the Magnificent"

let age = 111

Arrays- lists of variables. Can contain any variable or a mix of different variables. Declared by surrounding variables in square brackets [], separated by commas. Can be accessed by referring to the index of the variable. Note indexes are counted starting at 0. You can use methods to change an array such as push() which adds to the end of the array and pop() which removes the last variable from the array. Note, declaring an array as const means that it cannot be assigned a completely new array, however the variables within the array can be changed and the array can still be added to and removed from.

const magicTricks = ["one card monte" , "52 card pick up" , "dude wheres my car?" , "pulling a hat out of a rabbit" , "I'll do this with my hands"]

magicTricks[3] = "something less horrifying for the children"

magicTricks.push("cutting a pigeon in half with a stick")
